# End-to-end Test Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Browser tests that run real VPython programs: a small read-only smoke set (A) for candidate versions and glowscript.org, and a robust single-user set (B1) for a throwaway local stack.

**Architecture:** Playwright through `pytest-playwright`, in the `mcr.microsoft.com/playwright/python:v1.55.0-noble` Docker image. Shared helpers in `tests/e2e/e2e_helpers.py`, fixtures and the `local_only` guard in `tests/e2e/conftest.py`. `run_e2e.sh` starts a fresh Datastore emulator plus Flask and runs everything against `http://localhost:8080`.

**Tech Stack:** Python 3.12, pytest, pytest-playwright 0.7.1, playwright 1.55.0, Flask (the app), Cloud Datastore emulator (`google/cloud-sdk:emulators`), Docker.

**Spec:** `docs/superpowers/specs/2026-11-19-e2e-suite-design.md`

## Global Constraints

- No test accounts in prod. Anything that can run against a non-local URL is anonymous and read-only; A asserts that no non-GET request was sent.
- `local_only` tests run only when `--base-url` has hostname `localhost`. Otherwise they are skipped, never run.
- No changes to the app (`ide/`, `lib/`, `untrusted/`, `package/`). The one exception allowed is in `tests/conftest.py` (Task 1).
- No fixed sleeps. Every wait is on a condition, capped at 20 s (`TIMEOUT = 20_000` ms).
- No screenshot comparison. Checks are: no errors, output marker, canvas colors, graph traces, widgets.
- Demos (Steve's picks): `VPythonObjects-VPython`, `Extrusions`, `GraphTest`, `ButtonsSlidersMenus-VPython`, in `GlowScriptDemos/Examples`.
- Run iframe selector is `#ajaxBody iframe.untrusted-frame`. `index.html` keeps a hidden template copy, so `iframe.untrusted-frame` alone matches two elements.
- Browsers: Chromium and WebKit.
- Never run npm code or the app on the host. Tests run in Docker.
- Work only in worktree `~/Development/glow-repos/glowscript-e2e`, branch `test/e2e-suite`. Do not push.

## Facts this plan relies on (verified 2026-11-19)

- Probe on glowscript.org, anonymous, both browsers: the four demos run in 2.5–5.3 s with no page errors and no non-GET requests. Playwright can evaluate inside the cross-origin sandbox frame (`https://sandbox.glowscript.org`).
- 3D demos: `canvas.activated` holds the scene. `await scene.__renderer.screenshot()` returns an image with 3–68 distinct sampled colors. `scene` is not a global; this is the lookup `untrusted/run.js:332-345` uses.
- `GraphTest` has no `<canvas>`. It draws one `.js-plotly-plot` with 200+ trace paths.
- `ButtonsSlidersMenus-VPython` has 3 widgets (`button, input[type=range], select`).
- `print()` output goes to `textarea#print` in the run frame (`lib/glow/api_misc.js:256`).
- Errors: run.js posts `{error, traceback}`, and the IDE opens a clone of `#program-error-dialog` with `.error-details` and `.error-traceback` (`ide/ide.js:1266-1282`).
- The editor is ACE, as `window.editor` (`ide/ide.js:1470`). Edits autosave after 1 s, and `.program-status` shows ` (Saved)`.
- Locally every request is `localuser@local.host`. `/api/login` returns `{state:'new_user'}` until a user is created, then `{state:'logged_in', username, secret}`. API writes need header `X-CSRF-Token: <secret>`, with a form field `program=<json>`.
- The run iframe is same-origin only when `document.domain == "localhost"` (`ide/ide.js:1111`). With `127.0.0.1` it would point at `https://sandbox.127.0.0.1`. **So local runs must use `localhost`**; the spec's "or 127.0.0.1" is narrowed here.
- A folder holding programs can't be deleted: DELETE returns 409 (`ide/routes.py`, `ApiUserFolder`).

## Review Focus

1. **A demo takes longer than 20 s on a cold candidate instance.** Expected: a clear timeout naming the demo, not a hang. Task 2 test `test_demo_runs` uses one `TIMEOUT` for all waits, and the failure message names the demo.
2. **`local_only` tests reached with a production URL.** Expected: skipped, and zero requests sent. Task 1 has `test_local_only_guard` for `https://glowscript.org`, `https://x-dot-glowscript.appspot.com`, `http://127.0.0.1:8080` and `http://localhost:8080`.
3. **A check that can't fail.** For example, a canvas check that passes on a blank scene, or an error check that misses the dialog. Expected: each check has a sabotage test proving it fails. Tasks 2, 5 and 7.
4. **Leftover data between local runs.** Expected: each `run_e2e.sh` run starts empty (`--no-store-on-disk`), and tests within a run use unique names. Task 4 checks that the user starts as `new_user`; Tasks 6–7 use a `uniq()` name.
5. **Console noise in WebKit vs Chromium** making the error check flaky. Expected: one explicit, commented allowlist. Task 2 builds it from observed runs in both browsers.

from urllib.parse import urlparse

TIMEOUT = 20_000  # ms; every wait in tests/e2e is on a condition with this cap
RUN_FRAME = "#ajaxBody iframe.untrusted-frame"  # index.html also holds a hidden template copy


def is_local(base_url):
    """True only for http://localhost[:port]. local_only tests write data, so anything else is refused."""
    return bool(base_url) and urlparse(base_url).hostname == "localhost"
```

def pytest_collection_modifyitems(config, items):
    base_url = config.getoption("--base-url")
    no_url = pytest.mark.skip(reason="browser test: pass --base-url")
    not_local = pytest.mark.skip(reason="local_only: writes data; runs only against http://localhost")

"""
Smoke tests (A): anonymous and read-only, safe against any server, prod included.

Run against a --no-promote candidate before switching traffic, and against
https://glowscript.org right after. Candidate (-dot-) URLs run programs same-origin;
only glowscript.org uses the cross-origin sandbox, so the post-switch run is the only
check of the real sandbox.

    pytest tests/e2e/test_smoke.py --base-url https://VERSION-dot-glowscript.appspot.com --browser chromium --browser webkit
"""
import pytest
from playwright.sync_api import Page
from tests.e2e.e2e_helpers import (DEMOS, program_url, run_frame, wait_for_drawing, wait_for_graph,
                                   widget_count, error_text, real_errors)


@pytest.mark.parametrize("name", list(DEMOS))
def test_demo_runs(page: Page, base_url, demo_user, page_errors, writes, name):
    page.goto(program_url(base_url, demo_user, "Examples", name))
    frame = run_frame(page)
    check = DEMOS[name]
    if check == "graph":
        wait_for_graph(frame)
    else:
        wait_for_drawing(frame)
    if check == "widgets":
        assert widget_count(frame) >= 3, f"{name}: expected its buttons, slider and menu"
    assert error_text(page) == "", f"{name}: error dialog: {error_text(page)}"
    assert real_errors(page_errors) == [], f"{name}: {real_errors(page_errors)}"
    assert writes == [], f"{name}: a smoke test must not write: {writes}"


def test_broken_package_is_caught(page: Page, base_url, demo_user):
    """Sabotage: with an empty glow package nothing can draw, so the drawing check must fail."""
    page.route("**/package/glow.*.min.js", lambda r: r.fulfill(body="", content_type="text/javascript"))
    page.goto(program_url(base_url, demo_user, "Examples", "Extrusions"))

# Steve's picks, 2026-11-19. Value = how the test knows the demo worked.
DEMOS = {
    "VPythonObjects-VPython": "drawing",
    "Extrusions": "drawing",
    "GraphTest": "graph",                     # Plotly only, no 3D canvas
    "ButtonsSlidersMenus-VPython": "widgets",  # also draws
}

# Console errors that are not ours. Each entry needs a comment saying where it comes from.
KNOWN_NOISE = []


def program_url(base_url, user, folder, program, page="run"):
    url = f"{base_url.rstrip('/')}/#/user/{user}/folder/{folder}/program/{program}"
    return url if page == "run" else f"{url}/{page}"


def run_frame(page):
    """The program's iframe, once run.html has loaded in it (cross-origin on glowscript.org)."""
    page.frame_locator(RUN_FRAME).locator("#glowscript").wait_for(state="attached", timeout=TIMEOUT)
    frames = [f for f in page.frames if "/untrusted/run.html" in f.url]
    assert frames, "the program frame never loaded untrusted/run.html"
    return frames[0]


# Distinct colors in a sample of the first activated 3D canvas, read the way the IDE's own
# thumbnails are (untrusted/run.js:332-350): a WebGL canvas can read back blank otherwise.
_CANVAS_COLORS = """async () => {
    const scene = (window.canvas && canvas.activated || []).find(c => c)
    if (!scene) return -1
    const img = await scene.__renderer.screenshot()
    const cv = document.createElement('canvas'); cv.width = img.width; cv.height = img.height
    const g = cv.getContext('2d'); g.drawImage(img, 0, 0)
    const d = g.getImageData(0, 0, cv.width, cv.height).data, seen = new Set()
    for (let i = 0; i < d.length; i += 4 * 997) seen.add(d[i] + ',' + d[i + 1] + ',' + d[i + 2])
    return seen.size
}"""


def canvas_colors(frame):
    """Distinct sampled colors in the 3D scene; -1 when no 3D canvas was created."""
    return frame.evaluate(_CANVAS_COLORS)


def wait_for_drawing(frame, min_colors=2):
    frame.wait_for_function(f"async () => ({_CANVAS_COLORS})().then(n => n >= {min_colors})",
                            timeout=TIMEOUT)


def wait_for_graph(frame):
    frame.wait_for_function(
        "() => document.querySelectorAll('.js-plotly-plot .scatterlayer path, .js-plotly-plot .trace').length > 0",
        timeout=TIMEOUT)


def widget_count(frame):
    return frame.evaluate("() => document.querySelectorAll('button, input[type=range], select').length")


def print_text(frame):
    return frame.evaluate("() => (document.querySelector('#print') || {value: ''}).value")


def wait_for_print(frame, text):
    frame.wait_for_function(
        "t => ((document.querySelector('#print') || {}).value || '').includes(t)", arg=text, timeout=TIMEOUT)


def error_text(page):
    """Text of any visible program-error dialog (ide/ide.js:1278), else ''."""
    return " | ".join(page.locator(".ui-dialog .error-details:visible").all_inner_texts()).strip()


def real_errors(errors):
    return [e for e in errors if not any(n in e for n in KNOWN_NOISE)]
```
